# Вкладка «Пропуск заставок (EDL)»

Находит в сериях интро и финальные титры и пишет рядом с каждой серией файл
`<имя серии>.edl`. По нему Kodi сам, без аддонов, пропускает эти куски: тихо, без
кнопки на экране, один раз за просмотр, и назад отмотать можно. В IINA так же
работает плагин [iina-edl-skip](#пропуск-в-iina). Та же разметка пишется в MKV
[главами](#главы-matroska) — их видят mpv, VLC и другие плееры.

Для автоопределения нужны ffmpeg и fpcalc — см. [что нужно](#что-нужно).

## Пошагово

1. **Указать папку** наверху → **«Сканировать»**. Таблица заполнится сериями. Если у
   серий уже есть `.edl`, тайминги из них подхватятся (заметка «из .edl»): можно
   поправить пару серий и перезаписать, не запуская определение заново.
2. **«Определить автоматически».** Программа сравнивает звук начала и конца серий
   сезона между собой и находит повторяющийся кусок — это и есть заставка и титры.
   Нужно хотя бы две серии в сезоне. Первый прогон занимает от секунд до нескольких
   минут на сезон, повторный идёт из кэша.
3. **Проверить таблицу.** Если у серии нет таймингов, колонка **«Заметка»** объясняет
   почему: «не найдено», «мало отпечатков», «нужно ≥2 серий в сезоне».
4. **Поправить, если нужно:**
   - одну серию — двойной клик по строке ([правка серии](#правка-одной-серии));
   - весь сезон одним временем — под-вкладка [«Задать вручную»](#задать-вручную);
   - взять тайминги из онлайн-баз — под-вкладка
     [«Главы и онлайн»](#онлайн-тайминги-aniskip--theintrodb).
5. **«Записать .edl».** Если звук в файле длиннее видео, сначала
   [обрезается хвост](#хвост-звука-после-конца-видео). Чтобы заодно записались
   [главы](#главы-matroska), включите «писать вместе с .edl».

**«Удалить .edl»** убирает файлы разметки. Настройки вкладки сохраняются между
запусками.

## Настройки пропуска

- **Показывать заставку в первой серии сезона** (включено по умолчанию) — в E01 каждого
  сезона интро не пропускается, титры пропускаются.
- **Дорожка для детекта** — по умолчанию «Оригинал (авто)»: первая нерусская дорожка
  (английская у западных сериалов, японская у аниме). В дубляже поверх заставки часто
  читают название серии, и это сбивает границы, а в оригинале музыка чистая.
- **Окно поиска (сек)** — сколько звука от начала и от конца серии слушает детект, по
  умолчанию 240 с. Заставка должна поместиться в окно целиком: то, что выходит за
  край, обрезается. Уменьшать окно стоит, только если заставка точно ранняя и короткая —
  так детект пойдёт быстрее.
- **Отступы (сек)** — сдвиг найденных границ для всего сезона: начало и конец интро,
  начало и конец титров. Плюс сдвигает позже, минус — раньше.
- **Титры — до конца файла** (включено по умолчанию) — пропуск идёт до самого конца
  серии, иначе Kodi покажет последние секунды чёрного экрана. Снимите галку, если
  после титров есть сцена: тогда пропуск закончится на найденной границе.
- **Обрезать хвост после конца видео** (включено по умолчанию) — см.
  [Хвост звука](#хвост-звука-после-конца-видео).

## Задать вручную

Одно время для всех серий (или для [выделенных](#только-часть-серий-применять-к)).
Время можно вводить в виде `MM:SS`, `H:MM:SS` или просто в секундах.

- **Интро** — начало и конец, или длительность от начала серии.
- **Титры** — начало и конец, или «последние N сек» от конца файла. Когда в плеере
  видно только, где титры начались, введите это время в «…знаете только начало» →
  **«Посчитать»**: программа вычтет его из длительности выделенной серии и подставит
  продолжительность титров.
- **Recap** («в предыдущих сериях») — от начала файла до указанного времени.
  Автоматически не ищется: у каждой серии он свой.
- **Убрать: интро / титры / recap / всё** — удалить сегмент, если детект нашёл лишнее
  (например, у мультсериала без титров).

## Правка одной серии

Двойной клик по строке открывает окно правки: интро, титры, recap. Длительность
каждого сегмента считается сама («длительность 1:42 = 102 сек»). Пустое поле означает,
что сегмента нет.

**Проверка кадром.** По числу «конец интро 0:29» не понять, что там на экране:
заставка, затемнение или уже серия. Выберите границу и шаг (1/2/5/10 с) → **«Показать
кадры»**: появится полоса из восьми кадров вокруг границы. Клик по кадру назначает его
время границей. Дальше:

- **«Применить к этой серии»** — только ей;
- **«Сдвинуть все серии на ±N с»** — добавить ту же разницу в отступ сезона. Детект
  обычно ошибается во всех сериях одинаково, поэтому общий сдвиг сохраняет их
  индивидуальные границы.

**«Открыть в IINA»** (или mpv, VLC — берётся первый найденный плеер) открывает серию
сразу на выбранном кадре или на самой границе.

## Только часть серий: «Применять к»

Переключатель **«ко всем сериям» / «к выделенным»** рядом с главными кнопками действует
на всю вкладку: «Задать», «Убрать», автоопределение, запись и удаление `.edl`. Строки
выделяются мышью с **Shift** или **Ctrl**.

Пример: в одной папке сезона склеены две части по 24 серии с разными заставками.
Выделяете первую половину и задаёте одно время, вторую — другое. Автоопределение по
выделению сравнивает серии только внутри выделенного, поэтому одной выделенной серии
ему мало.

Клик по заголовку колонки сортирует таблицу: так серии, где интро не нашлось, легко
собрать вместе.

## Главы Matroska

`.edl` читают только Kodi и IINA с плагином [iina-edl-skip](#пропуск-в-iina). mpv,
VLC и другие плееры его не читают, зато понимают главы. Поэтому та же разметка
пишется в MKV главами: `Cold Open`, `Recap`, `Intro`, `Episode`, `Credits`. Главы
лежат внутри файла и не теряются, если файл перенесли без `.edl`: тогда плагин для
IINA пропускает заставки по ним.

- **«писать вместе с .edl»** (выключено по умолчанию) — «Записать .edl» пишет и главы
  тоже.
- **«Записать главы»** — только главы, когда `.edl` уже есть.
- **«Убрать главы»** — удаляет только главы, записанные программой.
- Колонка **«главы»** показывает, сколько глав уже в файле.

Главы пишет `mkvpropedit`: меняется только заголовок, видео не перекодируется, на это
уходят доли секунды.

⚠ **Чужие главы.** Главы в файле можно только заменить целиком, дописать к ним нельзя.
У фильмов в главах часто осмысленное деление на сцены, поэтому файлы с чужими главами
по умолчанию пропускаются. Заменить их можно галкой «перезаписывать чужие главы».
Свои главы программа узнаёт по названиям из списка выше и перезаписывает без вопросов.

## Пропуск в IINA

Сам IINA `.edl` не читает. Пропуск в нём делает плагин
[iina-edl-skip](https://github.com/BaldPanther/iina-edl-skip): он читает те же `.edl`,
а если их нет — главы Recap, Intro и Credits. Пропускает так же, как Kodi: сам, один
раз за просмотр, а ⌥⌘Z отменяет последний пропуск.

Установка: IINA → **Настройки → Плагины → Install from GitHub** → ввести
`BaldPanther/iina-edl-skip`.

## Хвост звука после конца видео

В некоторых релизах звук длиннее картинки: видео с титрами укоротили, а дорожки
озвучки оставили целиком. На таких файлах Kodi, пропуская титры, встаёт посреди них,
а после конца видео показывает чёрный экран, пока не кончится звук. Следующая серия
включается только через полминуты. Почему так происходит — в
[технических подробностях](technical.md#почему-kodi-спотыкается-о-хвост-звука).

Галка **«Обрезать хвост после конца видео»** решает это: перед записью `.edl` такие
файлы обрезаются по концу видео.

- Колонка **«хвост»** показывает, на сколько звук длиннее видео, если разница больше
  2 с.
- Обрезка идёт **без перекодирования**: картинка и звук остаются бит в бит, главы и
  вложения сохраняются.
- **Оригинал заменяется только после сверки** нового файла с ним. Если что-то не
  сошлось, оригинал остаётся как был, а причина пишется в лог.
- Файл переписывается целиком, это небыстро: несколько минут на серию в 8 ГБ по сети.
  Серии обрабатываются по одной: обрезка, `.edl`, главы, затем следующая серия. Где
  бы работа ни прервалась, готовые серии готовы целиком, а остальные не тронуты.
- **«Отмена»** посреди обрезки оставляет файл как был.
- **Обрыв сети.** Если сетевой диск пропал посреди серии, программа ждёт, пока он
  вернётся, и повторяет шаг. «Отмена» прерывает ожидание.

Нужны ffmpeg и MKVToolNix. Если чего-то не хватает, запись сообщит об этом и
предложит снять галку.

## Онлайн-тайминги (AniSkip / TheIntroDB)

Готовые тайминги из баз помогают, когда автоопределение ошибается. **«Загрузить
онлайн…»** загружает их в отдельные колонки **«Интро (онлайн)»** и **«Титры (онлайн)»**
рядом с найденными — видны обе версии.

- **AniSkip** — аниме, по ID MyAnimeList. **TheIntroDB** — сериалы и фильмы, по
  TMDb-ID или IMDb-ID.
- **«Авто-подобрать»** находит ID сама: TMDb-ID берётся из `tvshow.nfo`, MAL-ID —
  поиском по названию. Если в MAL сезон разбит на части, серии тоже разбиваются по
  ним. Подобранное можно поправить перед загрузкой.
- **«Взять онлайн»** переносит онлайн-тайминги в рабочие, из которых пишется `.edl`,
  **«Вернуть локальные»** — наоборот. Где онлайн-данных нет, локальные остаются.

Ключи не нужны, нужен интернет. У аниме покрытие обычно хорошее, у западной анимации и
редких сериалов часто пусто.

## Что нужно

- **ffmpeg** и **fpcalc** (Chromaprint) — для автоопределения, проверки кадром и
  обрезки хвоста. В Docker-образе есть, в сборке для Windows есть fpcalc, остальное
  — см. [Установка](../README.md#установка).
- **numpy** — есть в сборках и Docker-образе, из исходников ставится через
  `requirements.txt`.

Без них работает всё остальное; вкладка сама подскажет, чего не хватает.
