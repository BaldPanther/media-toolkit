# Технические подробности

Для тех, кто запускает программу из исходников или хочет знать, как она устроена.
Пользоваться программой можно, не читая этот раздел.

## Запуск из исходников

Нужно:

- **Python 3** с модулем `tkinter`. На macOS нужен Tk 8.6+: у системного Python
  Tk 8.5, и интерфейс в нём выглядит плохо. Ставится через `brew install python-tk@3.14`.
- **MKVToolNix** (`mkvmerge`, `mkvpropedit`) — обязательно. Нужна свежая версия:
  старый mkvmerge (например, v82 из Ubuntu 24.04) не отдаёт статистику дорожек, и
  программа не видит хвост звука после конца видео. v92 и новее подходят.
- **ffmpeg** и **fpcalc** (Chromaprint) — для вкладки «Пропуск заставок». На Windows
  `fpcalc.exe` можно положить в `assets/` (в репозиторий он не входит).
- Python-пакеты — `pip install -r requirements.txt`. Все необязательные:

  | Пакет | Для чего | Без него |
  |---|---|---|
  | `numpy` | автоопределение заставок | вкладка EDL подскажет установить |
  | `subliminal` | русские субтитры | кнопка скачивания подскажет установить |
  | `pillow` | миниатюры в сетке выбора картинок | картинки выбираются автоматически |
  | `send2trash` | удаление мусора в Корзину | галка «удалять мусор» заблокирована |

```bash
python app.py                        # открыть окно
python app.py "/путь/Сериал/Season 01"   # с подставленной папкой; есть .mkv — сразу скан
```

**Ярлыки.** На macOS `bash make_app.sh` собирает «Media Toolkit.app» в `~/Applications`:
его видят Spotlight, Launchpad и Dock. Путь к проекту зашивается при сборке — если
перенести папку, соберите заново. Если приложение не открылось, причина будет в
`~/Library/Logs/Media Toolkit.log`.

На Windows `make_shortcut.ps1` создаёт ярлык на `pythonw.exe` на рабочем столе. Путь к
`pythonw.exe` и стартовая папка заданы в начале скрипта — поправьте их под себя. Ярлык
нужен потому, что на некоторых системах запуск `.bat` двойным кликом блокируется
политикой запуска скриптов; `run.bat` работает из `cmd`.

**Где ищутся внешние программы.** Сначала в `PATH`, затем в папках Homebrew
(`/opt/homebrew/bin`, `/usr/local/bin`) на macOS и в `C:\Program Files\MKVToolNix` на
Windows. Папки Homebrew важны: программа, запущенная из Dock или Finder, получает от
системы `PATH` без них.

## Проверка зависимостей

```bash
python app.py --selfcheck отчёт.txt          # или "Media Toolkit.exe" --selfcheck …
```

Окно не открывается. Каждая зависимость проверяется по-настоящему, в отчёте — строка
на каждую: `ok` / `FAIL` / `нет`. Так проверяется и каждая сборка перед релизом.

## Отчёт из командной строки

```bash
python core.py "/путь/Сериал/Season 01" --recursive
```

Выводит список дорожек с числом файлов, где они есть, и число разных раскладок. Ничего
не меняет.

## Как меняются дорожки по умолчанию

- `mkvmerge -J` читает дорожки: тип, язык, название, UID, флаг default.
- Целевая дорожка адресуется по UID (`mkvpropedit --edit track:=<uid>`), поэтому её
  номер в файле не важен.
- Меняется только флаг `flag-default`, у файла ровно одна аудиодорожка по умолчанию.
  Видео и обложки не трогаются.

## Автоопределение заставок

По каждому сезону считаются аудио-отпечатки (Chromaprint, `fpcalc`) начала и конца
всех серий, и между сериями ищется повторяющийся фрагмент. Это находит заставку, даже
если перед ней идёт вступление разной длины, и не зависит от языка титров: сравнивается
звук. Каждая серия сравнивается с несколькими другими, границы берутся по медиане —
так одна нетипичная серия не сбивает остальные. Фрагменты короче `MIN_LEN_S` (10 с) не
считаются заставкой.

Сезон и номер серии берутся из имени файла (`SxxEyy` или `NxNN`).

**Окно поиска** должно вмещать заставку целиком. Пример — сериал с интро по звуку
≈ 0:00–0:17:

| Окно | Результат |
|---|---|
| 240 с | `0–17 с` — верно |
| 30 с | `0–18 с` — верно |
| 20 с | у трёх серий `0–20 с` (обрезано по краю окна), у четвёртой «не найдено» — внутри оказалось меньше 10 с |

### Скорость и кэш отпечатков

Скорость упирается не в процессор, а в чтение файла. Чтобы добраться до звука в MKV,
ffmpeg читает нужный кусок вместе с видео: дорожки в контейнере перемешаны. Время
поэтому растёт с битрейтом. Замеры на гигабитной SMB-шаре (≈86 МБ/с):

| Битрейт | Окно 240 с | Время окна | Сезон из 10 серий (2 окна на серию) |
|---|---|---|---|
| 1.8 Мбит/с | 53 МБ | ~0.6 с | ~12 с |
| 6.7 Мбит/с | 200 МБ | ~2.3 с | ~46 с |
| 23.8 Мбит/с | 713 МБ | ~8.3 с | ~2.8 мин |

Параллельное чтение не ускоряет: 8 окон в 1 поток — 51.6 с, в 4 потока — 55.5 с,
в 8 — 54.9 с. Один поток уже занимает весь канал.

Поэтому отпечатки кэшируются на диск, в `fingerprints/` внутри
[каталога кэша](setup.md#где-лежат-настройки). Повторное определение той же папки
идёт из кэша: 23.3 с против 0.1 с на трёх сериях. Одна запись занимает около 10 КБ.
Ключ записи — путь, размер и время изменения файла, номер дорожки и границы окна:
изменился файл — изменился ключ. Пороги сравнения (`BIT_THR` и прочие) в ключ не
входят: на извлечение они не влияют, и менять их можно без пересчёта. Записи, которых
не касались 90 дней, удаляются при следующем определении.

## Формат `.edl`

Строки `начало конец 3`, время в секундах. Действие 3 — commercial break: Kodi
пропускает сегмент автоматически один раз за просмотр, и назад отмотать можно.

mpv и плееры на нём (IINA) такой файл не используют: в mpv «EDL» — формат склейки
кусков в общий таймлайн, а не список пропусков. Поэтому та же разметка пишется и
главами Matroska.

## Почему Kodi спотыкается о хвост звука

Длительность файла считается по самой длинной дорожке. Если звук длиннее видео, туда
же попадает конец титров в `.edl`, и Kodi на пропуске делает вот что:

1. Прыгает к концу титров, но встать может только на ключевой кадр — последний перед
   целью, то есть на полпути по титрам.
2. Если цель дальше этого кадра больше чем на 20 с, Kodi отказывается от точного
   перехода (`CheckPlayerInit` в `VideoPlayer.cpp`, «too far to decode before
   finishing seek») и играет с ключевого кадра: остаток титров, а потом чёрный экран,
   пока не кончится звук.

Значением в `.edl` это не лечится: цель должна быть и за концом звука, и не дальше
20 с от ключевого кадра, а одновременно так не бывает. mpv и IINA этим не страдают:
прыжок за конец файла сразу включает следующий. Поэтому лечится сам файл —
обрезкой хвоста.

## Как устроена обрезка хвоста

- Хвостом считается разница больше 2 с между концом видео и концом самой длинной
  **аудио**дорожки. Субтитры не учитываются: надпись, висящая на пару секунд дольше
  картинки, бывает и в нормальных релизах, и Kodi она не мешает.
- Длительности дорожек берутся из статистики в `mkvmerge -J`. Если статистики в файле
  нет (её пишет не каждый муксер), хвост не виден, и файл не трогается.
- ffmpeg перекладывает пакеты в новый контейнер без перекодирования, обрывая каждую
  дорожку на конце видео. Потом `mkvpropedit` возвращает то, что ffmpeg теряет или
  пишет по-своему: вложения (обложку ffmpeg превратил бы в лишнюю видеодорожку
  `V_MJPEG`), главы — подрезанные по новому концу, с языками и UID, флаги,
  `DefaultDuration`, лишний `BitDepth` у AC-3/AAC. Статистика дорожек пересчитывается.
- Перед заменой оригинала новый файл сверяется с ним: те же дорожки и свойства, те же
  заголовки кодеков (сброшенный ffmpeg флаг `array_completeness` у HEVC прощается),
  начала дорожек не сдвинулись, число видеокадров совпало, вложения и главы на месте.
  Не сошлось — временный `<имя>.trim-tmp` удаляется, оригинал не тронут. Резервных
  копий не остаётся.
- Замер: серия 8.3 ГБ на SMB-шаре — перепаковка ~3 мин, пересчёт статистики ~1.5 мин.
- **Обрыв сети.** Если шаг (обрезка, `.edl`, главы) упал, программа проверяет,
  открывается ли файл. Пропал (macOS при обрыве отмонтирует шару) — ждёт, пока он
  вернётся, и повторяет шаг; обрезку — с начала, удалив недописанный `.trim-tmp`.
  После четвёртого обрыва подряд шаг записывается в неудачные.
- Если «Отмена» нажата после обрезки серии, её `.edl` и главы всё равно дописываются
  (это секунды) — иначе обрезанный файл остался бы со старым `.edl`.

## Плеер для проверки кадром

Поддерживаются IINA, mpv и VLC, берётся первый найденный. У IINA есть `iina-cli`, но в
`PATH` его обычно нет. Сам бинарник всегда лежит в
`/Applications/IINA.app/Contents/MacOS/iina-cli`, и программа запускает его оттуда.

Плееру передаются два флага:

- `--no-stdin` — иначе IINA принимает stdin за входной поток и отвечает «не удаётся
  открыть файл или поток»;
- `--mpv-resume-playback=no` (у mpv — `--no-resume-playback`) — иначе сохранённая
  позиция просмотра из `watch_later` перебивает запрошенное время.

Кадры для проверки извлекает ffmpeg параллельно, в PNG — Pillow для этого не нужен.

## Тесты

```bash
pip install pytest
python -m pytest tests/ -q
```

Покрыта чистая логика: разбор сезона и серии, отступы, формат и чтение `.edl`,
сводка дорожек, план изменений, команда `mkvpropedit`, раскладка медиатеки (имена,
план переименования, применение на тестовом дереве), генерация `.nfo`, разбор ответов
TMDb, Fanart.tv и OMDb. Тесты не трогают реальные MKV и не ходят в сеть. Исключение —
`test_trim.py`: он сам собирает маленький MKV с помощью ffmpeg и mkvmerge во временной
папке, а без них пропускается.

## Файлы проекта

Общее:

- `app.py` — окно программы: общее поле пути, три вкладки, лог и прогресс.
- `theme.py` — цвета подсветки строк под системную тему.
- `net.py` — HTTP для всех онлайн-источников: JSON с повторами, скачивание файлов.
- `paths.py` — где лежат настройки и кэш.
- `selfcheck.py` — проверка зависимостей (`--selfcheck`).

Вкладка «Медиатека»:

- `metaui.py` — интерфейс вкладки: опознание, сетка выбора картинок, таблица плана,
  настройки.
- `metadata.py` — сведение TMDb, Fanart.tv и OMDb, ранжирование картинок.
- `tmdb.py`, `fanart.py`, `omdb.py` — клиенты API.
- `library.py` — имена и раскладка: разбор папки, план переименования, применение,
  мусор.
- `nfo.py` — генерация `.nfo`, перенос отметок просмотра.
- `artwork.py` — скачивание картинок и кэш миниатюр.
- `metaconf.py` — настройки скрапера.

Вкладки «Дорожки и субтитры» и «Пропуск заставок»:

- `core.py` — поиск MKVToolNix, сканирование, сводка дорожек, план, применение;
  работает и как отчёт из командной строки.
- `subs.py` — русские субтитры через `subliminal`.
- `edl.py` — `.edl`: разбор сезона и серии, автоопределение, отступы, запись и чтение.
- `online.py` — тайминги из AniSkip и TheIntroDB.
- `chapters.py` — главы Matroska.
- `trim.py` — обрезка хвоста звука со сверкой и повтором после обрыва сети.
- `pipeline.py` — запись серия за серией: обрезка → `.edl` → главы.

Сборка и запуск:

- `Dockerfile`, `docker/`, `docker-compose.yaml`, `docker-compose.zimaos.yaml` —
  Docker-образ и запуск на сервере.
- `packaging/` — спека PyInstaller для Windows и macOS, лицензии сторонних
  компонентов.
- `make_app.sh`, `make_shortcut.ps1`, `run.bat` — ярлыки для запуска из исходников.
- `requirements.txt` — Python-пакеты.
- `tests/` — тесты.
