# Настройка

Всё здесь делается один раз. Обязателен только ключ TMDb — без него не работает
вкладка «Медиатека». Остальное добавляет возможности.

## Ключи API

Все ключи бесплатные.

| Сервис | Для чего | Без ключа |
|---|---|---|
| [TMDb](#tmdb--обязателен) | описания, картинки, названия серий | вкладка «Медиатека» не работает |
| [Fanart.tv](#fanarttv) | больше вариантов логотипов и постеров | в сетке выбора только картинки TMDb |
| [OMDb](#omdb) | рейтинг IMDb в `.nfo` | в рейтингах только themoviedb |
| [OpenSubtitles](#opensubtitles) | русские субтитры | русских субтитров почти не найдётся |

Все настройки — в окне **«Настройки»**: шестерёнка вверху справа на странице (на
вкладке «Медиатека» его же открывает кнопка «Настройки скрапера…»). Ключи TMDb,
Fanart.tv и OMDb — в разделе **«Ключи API»**. Ссылка **«Получить ключ»** рядом с каждым
полем открывает страницу выдачи ключа в новой вкладке. Ключ вставляется обычным
Ctrl+V / ⌘V. Сохраняет всё кнопка **«Сохранить»** внизу окна.

### TMDb — обязателен

1. Зарегистрироваться на [themoviedb.org](https://www.themoviedb.org/signup).
2. Открыть [настройки API](https://www.themoviedb.org/settings/api) → **Create** →
   тип **Developer** → заполнить анкету. Для личного использования подойдёт
   любое внятное описание.
3. Скопировать **API Key (v3 auth)** (32 символа) и вписать в «Настройки» → «Ключи API».

### Fanart.tv

1. Зарегистрироваться на [fanart.tv](https://fanart.tv/login/).
2. Открыть [страницу выдачи ключа](https://fanart.tv/get-an-api-key/) → добавить
   проект → скопировать **project API key**.

### OMDb

Kodi показывает рейтинг IMDb первым, а в TMDb API его нет — он берётся из OMDb.

1. Открыть [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx), выбрать
   **FREE (1000 запросов в сутки)**, указать почту.
2. Ключ придёт письмом. Без клика по ссылке активации в том же письме ключ не
   заработает.

### OpenSubtitles

Русские субтитры есть почти только на OpenSubtitles, а там нужен аккаунт. «Настройки»
→ раздел **«OpenSubtitles»** (на вкладке «Дорожки и субтитры» его открывает кнопка
«OpenSubtitles…»):

1. Зарегистрироваться на [opensubtitles.com](https://www.opensubtitles.com/).
2. Профиль → **Consumers** → **New consumer** → скопировать **API key**.
3. Вписать логин, пароль и API-ключ → **«Сохранить»**.

Галка «Использовать запасные провайдеры (podnapisi/tvsubtitles/gestdown)» добавляет
источники без аккаунта: для русского там обычно пусто, но иногда выручают.

Пароль хранится открытым текстом: OpenSubtitles требует его для входа, одного ключа
мало. У бесплатного аккаунта есть суточный лимит скачиваний. Когда он кончится,
программа остановится и сообщит об этом — остальное можно докачать на следующий день.

## Корни библиотеки

«Настройки» → **«Корни библиотеки»** → **«Добавить…»** под «Фильмы» или «Сериалы»:
откроется окно выбора папки. Здесь указываются папки, где лежат фильмы и сериалы.
Папок каждого вида может быть несколько. В Docker это папки внутри `/media`.

Для чего они нужны:

- **Тип «авто»**: программа понимает, фильм перед ней или сериал. Без корней
  тип определяется по структуре папки: есть ли в ней `Season NN` и `SxxEyy` в
  именах файлов. Это тоже работает, но с корнями надёжнее.
- Кнопки **«Что не обработано…»** и **«Убрать служебные файлы…»** обходят именно
  корни.

## Остальное в «Настройках»

- **«Языки и имена»**: **язык описаний** — язык `.nfo`, по умолчанию русский; **язык
  имён папок и файлов** — см. [Языки](library.md#языки).
- **«Картинки»**: **языки картинок** — порядок предпочтения, по умолчанию «русский,
  английский, без текста». Стрелки на плашке меняют порядок, «×» убирает язык,
  «Добавить язык…» — из списка, «Добавить код» — любой двухбуквенный код (например,
  `pl`). **Размер постера** — 342 / 500 / 780 px или оригинал. На скорость работы не
  влияет: файл скачивается один раз, а на экран его масштабирует Kodi.

## Где лежат настройки

Настройки хранятся не в папке программы, а в пользовательском каталоге системы.
Обновление или удаление программы их не затрагивает.

| Система | Каталог |
|---|---|
| macOS | `~/Library/Application Support/media-toolkit/` |
| Windows | `%APPDATA%\media-toolkit\` |
| Linux | `~/.config/media-toolkit/` (или `$XDG_CONFIG_HOME`) |
| Docker | `/config/xdg/config/media-toolkit/` (в compose `/config` — это `./config`, на ZimaOS — `/DATA/AppData/media-toolkit`) |

- `meta_settings.json` — ключи TMDb, Fanart.tv и OMDb, языки, корни библиотеки,
  выбранный язык имени для отдельных тайтлов.
- `subs_settings.json` — логин, пароль и API-ключ OpenSubtitles.
- `settings.json` — последняя папка и настройки вкладки «Пропуск заставок».
- `web-secret.key` — ключ, которым подписан вход по паролю (только с `WEB_PASSWORD`):
  с ним вход переживает перезапуск программы.
- `media-toolkit.log` — журнал сборки без консоли (Windows, `.app`), если что-то не
  запустилось.

Кэш — аудио-отпечатки серий — лежит отдельно, в `~/Library/Caches/media-toolkit/`
(Windows — `%LOCALAPPDATA%\media-toolkit\`, Linux — `~/.cache/media-toolkit/`, Docker —
`/config/xdg/cache/media-toolkit/`). Его можно удалить без потерь: он наполнится заново.
