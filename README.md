# Media Toolkit — подготовка медиатеки для Kodi

Скачанный сериал нельзя сразу нормально смотреть в Kodi. Сначала приходится:

- переименовать папку и файлы и разложить серии по сезонам — иначе Kodi не узнает
  сериал или перепутает серии;
- найти описание, постер и фон;
- в каждой серии переключать озвучку на нужную — а она в каждом файле под своим
  номером;
- искать русские субтитры;
- в каждой серии проматывать заставку и титры.

Media Toolkit делает всё это для целого сериала или фильма за раз — в одном окне, по
одной указанной папке. Видео не перекодируется, а перед изменениями показывается,
что именно поменяется.

## Возможности

**[Медиатека](docs/library.md)** — имена, описание, картинки

- опознаёт фильм или сериал в TMDb по имени раздачи;
- переименовывает папку и файлы и раскладывает серии по сезонам так, как ждёт Kodi;
- пишет `.nfo` с описанием и рейтингами, качает постер, фон, логотип и постеры сезонов;
- убирает мусор раздачи (`RARBG.txt`, `Sample`, скриншоты) в `Extras/`;
- показывает, какие папки библиотеки ещё не обработаны;
- разбирается с аниме, у которых нумерация сезонов на диске расходится с TMDb.

**[Дорожки и субтитры](docs/tracks.md)** — озвучка по умолчанию

- ставит озвучку и субтитры по умолчанию во всех сериях разом — по названию дорожки, а
  не по номеру;
- меняет только заголовок файла: серия на 8 ГБ обрабатывается за доли секунды;
- качает русские субтитры файлом `.ru.srt` рядом с серией.

**[Пропуск заставок](docs/edl.md)** — Kodi сам проматывает интро и титры

- находит интро и титры по звуку, сравнивая серии сезона между собой;
- пишет `.edl`, по которому Kodi пропускает их без аддонов;
- пишет ту же разметку главами MKV — для IINA, mpv и других плееров;
- берёт готовые тайминги из AniSkip и TheIntroDB;
- позволяет поправить границы вручную, сверяясь с кадрами;
- чинит релизы, где звук длиннее видео и Kodi после титров показывает чёрный экран.

Работает на Windows, macOS и в Docker на сервере или NAS — там интерфейс
открывается в браузере.

## Установка

Готовые сборки — на странице
[Releases](https://github.com/BaldPanther/media-toolkit/releases). Python ставить не
нужно, он внутри.

### Windows

1. Установить [MKVToolNix](https://mkvtoolnix.download/downloads.html#windows) —
   обязательно.
2. Установить ffmpeg — нужен для пропуска заставок: `winget install Gyan.FFmpeg`.
3. Скачать `MediaToolkit-windows-x64.zip`, распаковать, запустить **«Media
   Toolkit.exe»**. Сборка не подписана: на «Windows защитил компьютер» нажать
   «Подробнее» → «Выполнить в любом случае».

### macOS (Apple Silicon)

1. Установить внешние программы: `brew install mkvtoolnix ffmpeg chromaprint`.
2. Скачать `MediaToolkit-macos-arm64.zip`, распаковать, перенести **«Media
   Toolkit.app»** в «Программы».
3. Сборка не подписана. При первом запуске: «Системные настройки» →
   «Конфиденциальность и безопасность» → «Всё равно открыть». Если macOS пишет, что
   приложение повреждено:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Media Toolkit.app"
   ```

На Mac с Intel — [из исходников](docs/technical.md#запуск-из-исходников).

### Docker (сервер, NAS, ZimaOS)

Программа работает рядом с медиатекой: файлы читаются с локального диска, а не по
сети. В образе `ghcr.io/baldpanther/media-toolkit` (amd64 и arm64) уже есть всё
нужное.

```bash
MEDIA_DIR=/путь/к/медиатеке docker compose up -d
```

- Compose-файлы: [docker-compose.yaml](docker-compose.yaml) — для любого сервера,
  [docker-compose.zimaos.yaml](docker-compose.zimaos.yaml) — для ZimaOS и CasaOS
  (App Store → Custom Install → Import).
- Интерфейс — `http://<адрес-сервера>:5800`. Медиатека внутри видна как `/media`.
- `USER_ID` / `GROUP_ID` — владелец файлов медиатеки на сервере (узнать:
  `id <пользователь>`). От его имени программа переименовывает файлы и пишет `.nfo`,
  `.edl`, картинки.
- Задайте `VNC_PASSWORD`, если в сети бывают чужие устройства: без пароля интерфейс
  откроет любой.

### Из исходников

Python 3 с Tk 8.6+, MKVToolNix, ffmpeg, Chromaprint, затем:

```bash
pip install -r requirements.txt
python app.py
```

Подробности — [Запуск из исходников](docs/technical.md#запуск-из-исходников).

**Что-то не работает?** Запустите программу с `--selfcheck отчёт.txt` — в отчёте будет
видно, какой зависимости не хватает.

## Первая настройка

Делается один раз:

1. Вкладка «Медиатека» → **«Настройки скрапера…»** → вписать **ключ TMDb**
   (обязателен, бесплатный). Кнопка «Получить…» рядом с полем откроет страницу, где его
   выдают. По желанию — ключи Fanart.tv (больше картинок) и OMDb (рейтинг IMDb).
2. Там же — **корни библиотеки**: папки с фильмами и с сериалами (кнопка
   «Добавить…»).
3. Для русских субтитров: вкладка «Дорожки и субтитры» → **«OpenSubtitles…»** →
   логин, пароль и API-ключ.

Как получить каждый ключ — [Настройка](docs/setup.md). Настройки хранятся отдельно от
программы и сохраняются при обновлении — [где они лежат](docs/setup.md#где-лежат-настройки).

## Как пользоваться

Вкладки идут в порядке работы. Поле «Папка» наверху общее для всех вкладок.

### 1. Выбрать папку

**«Обзор…»** — папка сериала, сезона или фильма. **«Файл…»** — фильм, лежащий одним
файлом. Или на вкладке «Медиатека»: **«Что не обработано…»** → выбрать строку →
**«Взять в работу»**.

### 2. Медиатека — имена, описание, картинки

1. **«Найти»** — название и год уже подставлены из имени папки. Если вариантов
   несколько, выберите нужный в списке.
2. Проверьте картинки. Чтобы заменить картинку, нажмите «Выбрать…».
3. Проверьте таблицу «Сейчас → Станет»: зелёные строки изменятся, серые уже в
   порядке, красные конфликтуют.
4. **«Применить».** Путь наверху сменится на новое имя папки, и она сразу
   просканируется для следующих вкладок.
5. В Kodi: **Настройки → Медиатека → Очистить библиотеку**, затем обновить — старые
   пути после переименования становятся битыми.

[Подробно о вкладке →](docs/library.md)

### 3. Дорожки и субтитры — озвучка по умолчанию

1. **«Сканировать»**, если сканирование не запустилось само. Галка «Включая вложенные
   папки» захватывает все сезоны сразу.
2. **«Аудио»** — выберите озвучку по названию. **«Субтитры»** — дорожку или
   «выключить субтитры».
3. Проверьте таблицу → **«Применить (дорожки/субтитры)»**.
4. Нужны русские субтитры — **«Скачать русские субтитры»**.

[Подробно о вкладке →](docs/tracks.md)

### 4. Пропуск заставок — `.edl` для Kodi

1. **«Определить автоматически».**
2. Проверьте таблицу. Если у серии пусто, колонка «Заметка» объяснит почему.
   Поправить одну серию — двойной клик по строке. Задать одно время на весь сезон —
   под-вкладка «Задать вручную».
3. **«Записать .edl».**

[Подробно о вкладке →](docs/edl.md)

«Найти», «Сканировать» и «Определить автоматически» только читают файлы, их можно
нажимать без опаски.
